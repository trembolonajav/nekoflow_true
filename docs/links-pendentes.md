# Inventário de links sem destino

Este inventário registra links `href="#"` preservados no Protocolo 01. Eles não receberam destinos
inventados e devem ser tratados no Protocolo 02.

| Área         | Classificação                 | Exemplos                                                                |
| ------------ | ----------------------------- | ----------------------------------------------------------------------- |
| Footer       | Funcionalidade futura         | Animes, Minha lista, Solicitar obra, Sobre, Ajuda, Termos e Privacidade |
| Calendário   | Destino de catálogo pendente  | Alguns lançamentos sem uma página dinâmica de obra/unidade              |
| Entrar       | Conteúdo institucional futuro | Termos, Privacidade e links auxiliares                                  |
| Obra         | Catálogo dinâmico pendente    | Recomendações/personagens sem rota própria                              |
| ObraLeitura  | Catálogo dinâmico pendente    | Recomendações sem rota própria                                          |
| HomeDirecoes | Estudo visual                 | Links deliberadamente inertes na rota de estudo                         |

Os links devem ser corrigidos somente quando houver uma rota verdadeira e um contrato de dados
correspondente. Não direcionar obras desconhecidas para Solo Leveling.
