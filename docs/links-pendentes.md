# Inventário de links sem destino

> Atualizado após o Protocolo 02: os links públicos foram ligados a destinos verdadeiros ou
> transformados em texto explicitamente indisponível. Permanecem com `#` apenas três controles da
> rota interna de estudo `/estudos/home-direcoes`.

Este inventário registra links `href="#"` preservados no Protocolo 01. Eles não receberam destinos
inventados e devem ser tratados no Protocolo 02.

| Área         | Classificação                 | Exemplos                                                                |
| ------------ | ----------------------------- | ----------------------------------------------------------------------- |
| Footer       | Resolvido / explicitamente pendente | Rotas reais; institucionais são texto desabilitado                 |
| Calendário   | Resolvido como ficha de obra  | Títulos abrem a obra sem prometer reprodução                            |
| Entrar       | Explicitamente pendente       | Termos, Privacidade e Ajuda indicam preparação                          |
| Obra         | Resolvido                     | Recomendações usam catálogo; ordem sem ID é informativa                 |
| ObraLeitura  | Resolvido                     | Recomendações usam destinos canônicos                                   |
| HomeDirecoes | Estudo visual                 | Links deliberadamente inertes na rota de estudo                         |

Os links devem ser corrigidos somente quando houver uma rota verdadeira e um contrato de dados
correspondente. Não direcionar obras desconhecidas para Solo Leveling.
